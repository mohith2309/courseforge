## 2024-05-24 - Bulk Course Enrichment Bottleneck
**Learning:** Performing an `Array.find()` inside a loop over a large dataset creates an O(N * M) performance bottleneck. In `server/server.js`, bulk course retrieval endpoints (`/courses/published` and `/admin/pending`) mapped over all courses to `enrich()` them with publisher details. Because `enrich` was running `users.find(...)` for every course, the time complexity was O(C * U) where C is the number of courses and U is the number of users.
**Action:** Always pre-instantiate a `Map` structure for user lists (or other joined datasets) *before* mapping over an array to achieve an O(1) lookup inside the loop, dropping the complexity to O(N + M). Updated the `enrich()` function to accept a `Map` as fallback, keeping backward compatibility.
