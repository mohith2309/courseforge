## 2024-06-14 - Map-based lookups for bulk course enrichment
**Learning:** The `enrich` function in `server/server.js` previously used an `Array.find` operation to match publisher IDs from a courses array with user data in a users array. For large catalogs (e.g. 5,000 items), this resulted in O(C*U) time complexity, creating a significant latency bottleneck (~192ms). Converting the users array to a `Map` structure prior to iteration optimizes lookups to O(1), bringing the overall time complexity down to O(C+U) and reducing latency (e.g. to ~14ms).
**Action:** When enriching arrays of objects with linked data from another collection in Node.js server routes, always pre-process the linked collection into a `Map` (keyed by ID) before mapping over the primary array to avoid O(N^2) latency regressions.
