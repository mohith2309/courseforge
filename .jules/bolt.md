## 2024-06-28 - O(N) Array Search Bottleneck in Bulk Enrichment
**Learning:** The `enrich` function (which joins publisher details to course listings) previously performed an O(N) `users.find()` search per course. When rendering bulk listings like `/courses/published` or `/admin/pending`, this degraded the overall operation to O(C * U) complexity, causing significant slowdowns (e.g., ~15x slower on large datasets).
**Action:** When performing bulk array mapping that requires lookup of relations (like joining users to courses), always pre-compute an O(1) lookup `Map` (e.g., `const userMap = new Map(users.map(u => [u.id, u]))`) before the loop. Update the inner function to support both `Map` (via `.get()`) and Array (via `.find()`) using `instanceof` to maintain backward compatibility for single-item processing while optimizing bulk processing to O(C + U).
